# 架构图布局压力测试集

这些 JSON 是布局回归输入。合成用例中的 `evidence` 仅用于验证 IR 结构与审计器行为，
不代表真实项目源码事实；本目录中的固定项目图仅用于跨项目布局回归。它们不规定生产图的行业、层名、模块命名或结构。生产架构图必须按当前项目源码满足 V2 契约。

合成结构由 `build_fixtures.py` 生成；固定项目图直接保存在本目录，不依赖历史项目输出。Pytest 会通过 `layout_fixture_support.py` 将固定输入转换为当前契约，并直接运行 schema 与几何审计。

覆盖：单模块层、12 模块层、3/7 层、标题 10 字与超限、无治理层、30 模块、密集跨层关系、
SDK 内核扩展、离线在线双链路、每层 2/3/4/5/6/7/9 个模块、4/5 相邻层错列、两个固定项目 IR，
以及 1:2/1:3/1:5 扇出、7:1 扇入、3:3 多对多、双向关系、时序返回和长标签。

分支用例重新生成：`python tests/layout_fixtures/build_branch_fixtures.py`

扇入、扇出、多对多、双向和时序返回另由 `tests/test_branch_routing.py` 回归。
